# Design and Development of a Promotional Website for Cynthias DressShop in San Jose de Buenavista, Antique

<h3>Developer: Jane Lhara G. Reyes | BSIT 3A</h3>
<h3>Framework Used: Bootstrap 5</h3>

## Project Overview
This project presents a promotional and informational website for Cynthias DressShop, a local clothing boutique in San Jose de Buenavista, Antique. The website was built to showcase trendy and budget-friendly fashion collections for teenagers, students, and everyday shoppers in the community.

The site includes a modern home page, featured categories, new arrivals, best sellers, promo highlights, an about page, and contact information. Its goal is to help visitors quickly explore products, discover current fashion offers, and connect with the shop for inquiries.
